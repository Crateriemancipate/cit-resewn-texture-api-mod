# CIT Resewn — Custom Item Texture API

[![Download Latest](https://img.shields.io/github/v/release/Crateriemancipate/cit-resewn-texture-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Crateriemancipate/cit-resewn-texture-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Re-implements OptiFine's Custom Item Textures (CIT) for Fabric without requiring OptiFine.

## Features

- OptiFine CIT format support on Fabric
- Custom textures for items based on NBT data
- Rename-based texture swapping via resource packs
- Enchantment glint override support
- Works with Sodium and all performance mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

- **Mod Loader:** Forge
